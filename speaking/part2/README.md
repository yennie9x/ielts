# IELTS Speaking Part 2 - Cue Cards & Sample Answers

## About Part 2 (Long Turn)
- Duration: 3-4 minutes total
- Preparation: 1 minute to prepare
- Speaking: 1-2 minutes to speak
- Format: Describe a topic using the cue card prompts

---

## Tips for Part 2

1. **Use all the prompts** - Address every point on the cue card
2. **Structure your answer** - Introduction → Main points → Conclusion
3. **Use the preparation time wisely** - Jot down key words, not full sentences
4. **Keep talking** - Aim for 1.5-2 minutes; don't stop too early
5. **Use varied vocabulary and grammar** - Show range
6. **Tell a story** - Make it engaging and personal

## Sample Structure Template

```
Introduction: What/Who is it?
↓
Point 1: When/Where/How did it happen?
↓
Point 2: Details and description
↓
Point 3: Why is it important/special?
↓
Conclusion: How you feel about it
```
