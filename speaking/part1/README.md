## Tips for Part 1

1. **Don't memorize** - Use these as inspiration, not scripts
2. **Be natural** - Speak like you're talking to a friend
3. **Give reasons and examples** - Don't just answer yes/no
4. **Stay on topic** - Don't wander off into unrelated areas
5. **Use varied vocabulary** - Avoid repeating the same words
6. **Practice pronunciation** - Focus on clear speech, not perfect accent
