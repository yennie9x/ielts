IELTS Reading review — Band 6.5
Goal: find the answer in the text. Do not answer from my own knowledge.

Time
[ ] About 20 minutes per passage
[ ] I do not get stuck on 1 question for more than 1 minute — mark it, move on
[ ] I leave no blank (guess if I must)

Method
[ ] I read the questions first, then the passage
[ ] I underline key words in the question (names, numbers, negatives: not / only / always)
[ ] I look for synonyms, not the same word (hire = employ = take on)
[ ] The answer is in order for most question types (True/False/NG, completion, short answer)

True / False / Not Given  (or Yes / No / Not Given)
[ ] True / Yes = the text says the same idea
[ ] False / No = the text says the opposite
[ ] Not Given = the text does not say this — I must not "think it is true in real life"
[ ] I do not choose True just because I see one similar word

Gap-fill / short answer
[ ] I copy the word(s) from the passage — same spelling
[ ] I follow the word limit (NO MORE THAN TWO WORDS, etc.)
[ ] Grammar in the sentence still works (a / the / plural -s)

Matching / headings
[ ] I read the paragraph for the main idea, not one example
[ ] If two headings look similar, I check which one covers the whole paragraph

After each passage
[ ] I check spelling and plurals
[ ] I check I wrote the answer next to the right number
[ ] Hard questions: I guessed and moved on — I did not lose time
